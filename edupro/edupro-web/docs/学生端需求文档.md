# EduPro 教务管理系统 - 学生端需求文档

## 一、功能概览

学生端是教务管理系统的学生入口，提供课表查看、选课、考试查询、违纪记录等功能。

### 1.1 核心功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 登录 | 学号+密码登录 | P0 |
| 首页 | 统计卡片+今日课表 | P0 |
| 我的班级 | 班级信息+同学列表 | P0 |
| 我的课表 | 按周查看课表 | P0 |
| 选课 | 浏览/报名/退选 | P1 |
| 考试 | 考试安排+成绩查询 | P1 |
| 违纪 | 违纪记录查看 | P2 |
| 个人中心 | 头像上传+信息编辑+修改密码 | P0 |

---

## 二、页面详细设计

### 2.1 登录页

- 学号输入框
- 密码输入框
- 登录按钮
- 登录成功后跳转到 `/stu/dashboard`

### 2.2 首页（Dashboard）

- 欢迎卡片：欢迎回来 + 当前班级
- 3个统计卡片：本学期课程、今日课程、违纪次数
- 今日课程表格：课程名、教师、教室、时间、节次

### 2.3 我的班级

- 班级信息卡片：名称、教室、学科、开课/结课日期、班主任
- 同学列表：姓名、学号、性别、手机号

### 2.4 我的课表

- 周选择器：上一周 / 下一周
- 课表网格：按星期×节次展示
- 每格显示：课程名、教室、教师

### 2.5 选课

- 可选课程列表：课程名、学科、教师、已选/容量、状态
- 操作：报名选课 / 退选
- 选课状态：已选 / 未选 / 已满

### 2.6 考试

- 考试安排列表：考试名、课程、时间、地点、状态
- 成绩查询：课程名、分数、排名

### 2.7 违纪

- 违纪汇总：总次数、总扣分
- 违纪详情列表：日期、类型、扣分、描述

### 2.8 个人中心

- 头像上传 + 基本信息展示
- 手机号、地址编辑
- 修改密码入口在右上角下拉菜单

## 五、注意事项

1. **班级归属**：班级由教师/管理员创建和管理，学生由教师/管理员分配到班级，学生端不需要"我的班级"创建功能
2. **课程 vs 班级**：课程（course）是学生选课的粒度，班级（clazz）是学生的行政归属
3. **多选课**：一个学生可以选择多门课程，选课记录存储在 `student_course` 表
4. **权限隔离**：学生只能查看自己的信息、已选课程、课表、考试和违纪记录
5. **Token区分**：学生Token和管理端Token需要区分，学生Token中存储 `role: "student"`
6. **头像上传**：复用现有的 `/api/upload` 接口
7. **退课限制**：每学期最多退选 3 次，学期开始由管理员设置
8. **自动分配**：选课结束后，未选课学生自动分配到未满员课程，优先填满最快的课程
9. **课表管理**：课表由管理员在后端维护（按课程排课），学生端只查看
10. **考试信息**：考试由管理员在后台安排（关联课程），学生端只查看，成绩由管理员录入
